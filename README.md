# 🪽 WHITE ANGEL - Defender dari Merauke

> Bukan untuk menyerang, hanya untuk menjaga.

Tool kecil buatan anak Merauke, Papua untuk melindungi teman dari link phising Robux palsu.

## 🚀 Cara Pakai - Tinggal Salin!
Semua orang bisa pakai, gratis!

1. Download file WHITE-ANGEL.PY di repo ini
2. Buka Termux di HP
3. Ketik: `python WHITE-ANGEL.PY`
4. Tempel link yang mencurigakan, tekan Enter

## Contoh
- `https://free-robux-generator.xyz` -> [BAHAYA! PHISING]
- `https://google.com` -> [AMAN]

## 🛡️ Fitur
- Deteksi kata bahaya: free-robux, rblx, gift
- 100% Aman, hanya mendeteksi
